## 관심사
- **AI에게 어디까지 맡기고 어디서 사람이 검증할지.**  
조회는 열어두고 변경은 승인 게이트 뒤에 두는 MCP 서버, AI가 쓴 코드도 같은 검수 체인을 통과하게 하는 pre-push 게이트처럼, AI를 많이 쓸수록 구조와 테스트가 더 중요해진다고 생각해요.
- **담당자가 바뀌어도 살아남는 코드.**   
레거시를 인수하면서 겪은 문제라 FSD 단방향 규칙, characterization 테스트, 문서만으로 투입 가능한 인수인계를 우선순위로 둡니다.
- **한 번 만들면 팀 전체가 빨라지는 것.**  
공통 테이블 시스템, 검수 체인, 사내 자동화 도구처럼 다른 개발자가 쓰는 코드를 만드는 일에 흥미가 있어요.
